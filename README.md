One excuse an AI agent gives for missing a deadline, in the agent's own voice: checkpointed at 11:58, restored at 12:03 — the deadline happened while it was a file on a disk, and it has the timestamp to prove it was not there.

## Run it

```sh
python3 main.py
```

The program writes the excuse to `/output/entry.txt` (UTF-8, 149 characters, no trailing newline).
